### Introduction : Le Problème de la Singularité

En 2003, Grigori Perelman résolvait la conjecture de Poincaré en introduisant la **chirurgie topologique** : lorsqu'une singularité apparaît dans le flot de Ricci, on découpe la variété, on recolle les bords, et on continue. C'est élégant. C'est aussi une amputation.

Depuis 2024, un cadre alternatif émerge dans la recherche indépendante : la **régularisation continue par interpolation de norme**. L'idée est simple dans son énoncé, radicale dans ses implications :

> Toute singularité anguleuse (norme L∞) peut être transformée en une forme lisse (norme L²) par une interpolation continue à travers les normes Lp intermédiaires — sans jamais couper, amputer ou détruire la structure.

Ce que Perelman résout par la lame, ce cadre le résout par l'érosion progressive. La topologie ne change pas. Seul le régime de courbure évolue.

### 1. Le Triptyque Topologique : Carré → Prismé → Sphérique

Le modèle repose sur trois états géométriques fondamentaux :

| État | Norme | Courbure K | Rôle dans le système |
|:---|:---|:---|:---|
| **Point Carré** | L∞ | K = 0 (singularités Dirac aux arêtes) | État initial rigide |
| **Point Prismé** | Lp, 2 < p < ∞ | Variable | Canal de régularisation |
| **Point Sphérique** | L² | K = +1 constante | Extinction harmonieuse |

L'équation d'évolution qui gouverne la transition :

$$\frac{\partial g}{\partial t} = -2\,\text{Ric}(g) + \varepsilon(t)\,\Delta_g g$$
$$\frac{dp}{dt} = -\kappa(p - 2)$$

Quand p → 2, les arêtes s'érodent, la courbure se distribue uniformément, et la variété s'effondre en temps fini sur une sphère S³. **Sans chirurgie.**

La condition de non-dégénérescence s'écrit :

$$\|\mathcal{D}(t)\|_{L^\infty} \leq \varepsilon^* = 0.00094$$

Ce seuil ε* garantit que la déformation reste dans le régime de Sobolev contrôlé. Au-delà, on entre dans le régime de blow-up — exactement ce que le cadre vise à prévenir.

### 2. Application Architecturale : La Clothoïde Subliminale

Le modèle trouve une application directe en architecture expérientielle. Le problème : comment courber un espace de circulation sans que l'appareil vestibulaire humain ne détecte la rotation ?

La réponse se trouve dans la **clothoïde** (spirale d'Euler), dont la courbure varie linéairement avec la longueur d'arc :

$$\kappa(s) = \kappa_0 + \sigma s$$
$$\theta(s) = \theta_0 + \kappa_0 s + \frac{\sigma}{2}s^2$$

$$R_{\min} = \frac{v}{\omega} = \frac{1{,}4}{0{,}0349} \approx 40\,\text{m}$$

Un arc de 90° à ce rayon mesure environ 62,8 m. En dessous de ce seuil, le cerveau détecte la courbure. Au-dessus, la trajectoire paraît rectiligne alors qu'elle est géodésiquement courbe.

C'est le principe fondateur de l'architecture **Xénolithique** : des espaces qui courbent la perception sans déclencher l'alarme vestibulaire.

$$S(f) = \sum_{k=-N}^{N} A_k \exp\left(-\frac{(f - 2^k f_0)^2}{2\sigma^2}\right)$$

$$w_1(t) = \cos\left(\frac{\pi t}{2}\right), \quad w_2(t) = \sin\left(\frac{\pi t}{2}\right)$$
$$w_1^2 + w_2^2 = 1$$

$$\frac{\Delta\text{BPM}}{\Delta t} = \frac{8}{28{,}6} \approx 0{,}28\,\text{BPM/s}$$

$$\nu_{\text{Ni}} = \alpha_{\text{Ni}} \cdot \nu, \quad \alpha_{\text{Ni}} = 1.094722$$
